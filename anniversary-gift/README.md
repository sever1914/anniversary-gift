# Подарок на годовщину — мобильный сайт по QR-коду

Чистые HTML/CSS/JS, без сборки и без внешних запросов. Открывается мгновенно в Safari на iPhone.

## Сценарий
1. **Пожелания** — тёмный фон `#060208`, текст проявляется по словам. Дальше: тап по экрану, свайп влево/вверх; назад: свайп вправо/вниз. Автоперехода нет, читать можно сколько угодно.
2. **Сердце** — фразы «Я люблю тебя» на 20 языках заполняют контур за ~14 секунд (алгоритм из `love.py`), потом сердце «оживает»: фразы мерцают и бьётся пульс. Касание пальцем пускает по фразам волну света.
3. **Сюрприз** — кнопка «Посмотреть сюрприз 🎬» появляется сама, когда сердце готово. Открывает плеер с видео и подписями по таймкодам.

## Структура
```
index.html          разметка трёх экранов
css/style.css       все стили, safe-area для iPhone, анимации
fonts/              Cormorant Garamond (локально, лицензия OFL)
assets/surprise.mp4 ← СЮДА кладёшь своё видео
js/config.js        ← ВСЕ ТЕКСТЫ, ФРАЗЫ, ПОДПИСИ — ТОЛЬКО ЗДЕСЬ
js/intro.js         экран пожеланий (тап/свайп)
js/heart.js         алгоритм love.py на Canvas + анимация
js/particles.js     фоновые искорки
js/video.js         плеер, подписи по таймкодам
js/main.js          сценарий между экранами
tools/make_qr.py    QR-код для открытки
tools/test_layout.js проверка раскладки сердца в Node
```

## Что заменить перед печатью
1. `js/config.js`: `herName`, тексты `wishes`, подпись `heart.caption`.
2. Видео в `assets/surprise.mp4` (или `youtubeId` для YouTube по ссылке).
3. Подписи по таймкодам: `video.captions` (`from`/`to` в секундах).

## Видео
Формат для iPhone: H.264 + AAC, `.mp4`, `faststart`. Для мобильного интернета 720p достаточно:
```
ffmpeg -i input.mov -c:v libx264 -profile:v high -pix_fmt yuv420p -crf 24 -preset slow \
  -vf "scale=-2:720" -c:a aac -b:a 128k -movflags +faststart assets/surprise.mp4
```
3 минуты — это примерно 15–25 МБ. Если в ролике фрагменты фильмов, на публичном хостинге на него может прийти жалоба правообладателя, поэтому после праздника сайт лучше закрыть.

## Как выложить (GitHub Pages, бесплатно)
1. Залей папку в репозиторий (`.gitattributes` уже есть).
2. Settings → Pages → Deploy from branch → `main` / root.
3. Через минуту сайт откроется по `https://<логин>.github.io/<репозиторий>/`.
4. Репозиторий публичный: дай ему неугадываемое имя. Скрытая ссылка не защита, но случайно на неё никто не попадёт.

Альтернативы: Cloudflare Pages, Netlify (перетащить папку в окно).

## QR-код
```
pip install "qrcode[pil]"
python tools/make_qr.py https://<логин>.github.io/<репозиторий>/
```
Получишь `qr.svg` (для печати) и `qr.png`. Печатай не меньше 2.5×2.5 см, с белой рамкой, и перед печатью отсканируй камерой iPhone по мобильному интернету, а не по Wi-Fi.

## Отладка
- `?skip` в конце ссылки сразу открывает сердце, без пожеланий.
- `node tools/test_layout.js` проверяет, что фразы не выходят за контур.
- Раскладка сердца детерминирована: `heart.seed` в конфиге меняет расположение фраз.

## Как `love.py` перенесён
| love.py | heart.js |
|---|---|
| `heart(a)`, `POLY` | `pt(a)`, `poly` (720 точек) |
| `spans(y)`, `intersect()` | то же, фраза гарантированно внутри контура |
| `build()`: укладка и растяжка строки | `buildLayout()` |
| порядок: контур, затем изнутри к центру | `edges.concat(inner)` |
| `spawn()/animate()`: тень, ореол, вспышка | `_drawItem()`, по времени, а не по кадрам |
| `shimmer()` | мерцание в состоянии `live` |

Отличия от прототипа: измерение текста через `canvas.measureText`, сердце вытянуто по вертикали под портретный экран, цвета чуть ярче для OLED.
